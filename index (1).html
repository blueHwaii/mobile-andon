Firebase 실시간 연동 가이드

  1. Firebase 콘솔에서 프로젝트를 만들고 Firestore Database를 생성합니다.
  2. 프로젝트 설정에서 웹 앱(</>)을 추가하고 firebaseConfig 값을 복사합니다.
  3. 이 index.html 파일을 메모장으로 열어 코드 하단의 [여기만 수정하세요] 영역에 값을 붙여넣고 저장합니다.
  4. Firestore 규칙(Rules) 탭에 아래 규칙을 붙여넣고 게시합니다.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /andon_calls/{docId} {
      allow read, write: if true;
    }
    match /andon_config/{docId} {
      allow read, write: if true;
    }
  }
}
